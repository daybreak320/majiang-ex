# DESIGN.md - 朱扬麻将理论精华 PPT 视觉设计

## 画布与母版

- 画布：1280×720
- 母版三区：A 标题块 0-120px / B 内容区 120-660px / C 页脚条 660-720px
- 页面 padding：上下 20px、左右 60px
- 封面/章节扉页/结束页采用自定义版式，省略 C 区

## 颜色系统

| 角色 | HEX | 用途 |

### 渐变与半透明
- 封面/扉页：`linear-gradient(135deg, #8B1A1A 0%, #6B1010 100%)` 做大色块
- 卡片半透明覆盖：`rgba(139,26,26,0.06)` 浅红铺底
- SVG 牌块阴影：`boxShadow: '0 2px 6px rgba(60,40,20,0.12)'`

## SVG 牌块设计规范

所有麻将牌使用 SVG 渲染，统一样式：

```
牌块尺寸：48×60px
圆角：rx=6
边框：1.5px solid #D8CBB4
背景：#FFFEF8
阴影：0 2px 6px rgba(60,40,20,0.12)
数字：bold 20px，居中
花色标注：11px，数字下方
```

花色颜色：
- 万：#1A7F5C（竹绿）
- 条：#2C5F2D（深绿）
- 筒：#C0392B（朱红）

特殊状态：
- 强组合牌：边框 #C9A227，外发光 `0 0 0 2px rgba(201,162,39,0.3)`
- 空位牌：虚线边框 #D8CBB4，背景 #FAF5EC，文字 #B8A98C
- 高亮进张：边框 #8B1A1A，背景微红 #FFF5F0

## 配图系统
