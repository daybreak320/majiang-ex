# 朱扬麻将理论：逐章阅读与工程转化地图

> 目的：在已购买的微信读书个人阅读权限内，逐章吸收两本书的理论，沉淀为可追溯的摘要、规则、反例与测试牌例。
>
> 版权边界：本文件只记录章节主题、工程映射与阅读状态，不包含或替代书籍全文；逐章阅读笔记和牌例素材保存到本地私有目录 `docs/theory/private/`，不得提交至公开仓库。
>
> 阅读状态：`待读` = 尚未完成结构化吸收；`已覆盖` = 现有公开理论库已有热门划线级别依据；`待验证` = 已有实现但需以逐章阅读补足条件/反例。

## 1. 完成标准

每一节完成后必须输出以下四种资产：

1. **理论卡**：定义、目标、适用前提、不能机械套用的情形。
2. **决策规则**：能否被程序计算、输入信息、输出影响与优先级。
3. **反例/边界**：机会数相同、定缺强制、残局安全、鸣牌后结构变化等。
4. **测试牌例**：给定手牌、牌河、鸣牌和牌墙，明确推荐动作及理由。

## 5. 执行顺序

1. 优先完成理论册上篇（机会数和组合）与成都册第二章（规则落地校验）。
2. 再完成成都册第一、三章（四川规则、攻防、杠牌和战术）。
3. 最后完成两书牌例、问答、番种和输赢策略，作为反例库与训练集。
4. 每完成一个主题，立即补充测试，不等全书读完才集成。

## 6. 当前基线与缺口

当前 `mahjong-theory-zhuyang.md` 已覆盖热门划线级别的：机会数、部分组合、放飞鸽、腾挪、踩线、残局安全、换三张、杠牌与部分番种。

仍然缺少逐章核验后的：计算边界、组合完整分类、同机会数时的裁决规则、鸣牌/杠牌后的数学口径、反例、完整牌局推导、各番种的目标切换条件及输赢策略。因此现有实现只能视为 **MVP 启发式**，不能宣称已完整复现朱扬理论。
