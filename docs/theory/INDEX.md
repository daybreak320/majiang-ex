# 朱扬麻将理论 · 公开索引与私有摘录边界

本目录服务于 `majiang-ex` 的规则引擎、赛中导师、复盘与专项训练。它区分三类材料，避免把读书摘录、工程推断和公开规则混为一谈。

## 使用顺序

1. 先读本文件，确定内容属于哪一层。
2. 需要可执行规则时，查 `../../src/knowledge/mahjongTheory.ts` 与测试 `../../src/knowledge/mahjongTheory.test.ts`。
3. 需要理论解释与章节溯源时，查 `mahjong-theory-zhuyang.md`。
4. 需要逐章细节、例外或牌例时，只能在本机 `private/` 内查阅经用户合法取得的个人摘录；不得把原文复制进公开仓库、提交到 Git 或发往外部服务。
5. 私有摘录不存在时，明确标注“现有公开摘要不足以支持该结论”，不得臆造作者原话或章节细节。

## 私有层（忽略，不提交）

`private/` 已在 `.gitignore` 中排除。仅存放用户自行合法获得的：

- 个人读书笔记；
- 短摘录与出处信息；
- 自制牌例、截图说明；
- 对公开理论的核验结论。

推荐文件名：

```text
private/
  opportunity-theory-notes.md
  chengdu-advanced-notes.md
  examples/
    2026-08-28-endgame-example.md
```

每条私有笔记建议包含：`书名 / 章节 / 页或位置（如有）/ 自己的转述 / 工程影响 / 反例`。不要建立书籍全文镜像。

## 当前工程能力与证据等级

- **已验证规则**：定缺限制、108 张牌实体、可见牌扣张、听牌/死听、碰杠合法性、公开牌河与副露风险。
- **启发式理论**：机会数、27/28/37/38 强组合、踩线、跟打优先级、杠后结构保护、做大趋势校正。
- **待逐章核验**：多张组合完整分类、同机会数的全部裁决条件、完整实战牌例、不同番种的全局输赢策略。

任何 UI 中的“理论建议”都应标明其基于可核验牌面事实还是启发式判断；不能把启发式包装成精确胜率，也不能声称已完整复现两本书。
