# 0.1.0-beta.1 内测测试计划

更新时间：2026-08-25
测试版本：`0.1.0-beta.1`
测试对象：5–8 名中高阶成都麻将玩家
单次时长：约 20 分钟

## 测试目标

本轮只验证 M1+M2：完整血战到底对局、存档恢复、终局结算和朱扬理论基础复盘。M3 专项训练、登录和云同步不在本次范围内。

## 测试者脚本

1. 打开邀请链接，确认页面显示 `0.1.0-beta.1`。
2. 点击“开始新局”，完成定缺并进行至少 5 次出牌决策。
3. 点击“暂停”，返回首页，再点击“继续牌局”，确认牌局和行动阶段没有改变。
4. 继续完成一局，观察 AI 行动、响应按钮、计时、牌墙和实时分数。
5. 在结算页核对排名、胡牌/杠分/终局赔付流水和最终分数。
6. 打开“朱扬理论复盘”，查看 2 个主要问题、1 个优秀决策和机会数趋势。
7. 对至少一条结论提交“认可”或“不认可”；选择“不认可”时填写原因。
8. 在手机竖屏设备重复开始、定缺、选牌、出牌和结算关键动作。
9. 填写反馈表单，记录设备、浏览器、牌局 Seed 和复现步骤。

## 发布前内部验收

- `npx vitest run`
- `npm run build`
- `npx eslint src/game src/review src/knowledge src/components src/App.tsx`
- 桌面宽屏、390px 手机竖屏和中等宽度浏览器检查
- 至少一组确定性牌局检查事件序号、牌实体守恒、分数守恒和终局状态
- 检查刷新、返回首页、切后台和暂停后的存档恢复
- 检查定缺强制出牌、响应倒计时、碰杠胡、抢杠胡、一炮多响和终局结算

`src/utils/tracker.ts` 的历史格式问题属于已知非阻断项，不纳入本次发布重构。

## 反馈表单字段

- 测试者昵称
- 设备、系统和浏览器
- 版本号和牌局 Seed
- 问题类型：规则、操作、恢复、结算、复盘、视觉、性能
- 严重度：阻断、严重、一般、建议
- 复现步骤
- 实际结果与预期结果
- 截图或录屏
- 规则正确性评分（1–5）
- 复盘结论可信度评分（1–5）
- 是否愿意再玩一局
- 其他建议

## 成功标准

- 至少 5 名测试者各完成 1 局完整牌局
- 复盘查看率达到 70% 以上
- 至少 70% 的有效反馈将规则正确性和复盘可信度评为 4/5 或以上
- 没有未解决的阻断问题
- 所有反馈能按版本、设备、Seed 和复现步骤归档
