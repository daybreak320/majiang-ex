- [ ] `npx vitest run` 通过

## 发布操作

- [ ] 创建发布提交
- [ ] 创建 Git tag `v0.1.0-beta.1`
- [ ] 在仓库 Settings → Pages 中将发布来源设为 GitHub Actions（首次配置）
- [ ] 推送 `main`，等待 GitHub Pages 工作流成功
- [ ] 用 `https://daybreak320.github.io/majiang-ex/` 重新走一遍开始新局和继续牌局
- [ ] 先邀请 2–3 名种子测试者

## 48 小时内测

- [ ] 每天整理一次表单反馈
- [ ] P0/P1 阻断问题出现时暂停继续邀请
- [ ] 修复后使用 `0.1.0-beta.2` 等补丁版本重新发布
- [ ] 记录完成局数、复盘查看率、规则/复盘可信度评分和未解决问题

## 回滚

保留发布前稳定提交 SHA。线上出现阻断问题时，优先暂停邀请并通过回退发布提交恢复上一版，再单独修复和发布补丁，不直接改写历史。GitHub Pages 不需要服务器账号、SSH 密钥或 Actions Secrets。
