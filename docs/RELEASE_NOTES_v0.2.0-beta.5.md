# 四川麻将练习 v0.2.0-beta.5

## 发布候选说明

本版本聚焦“训练→决策→解释→复盘→趋势”的连续体验，并针对手机端 390px 竖屏完成布局收敛。

## 主要变化

- 新增首页训练总览与专项训练库入口，支持从建议直接开始训练。
- 实战牌桌默认隐藏导师推荐，专项答题完成后展示结论、证据、原因与下一步。
- 局后复盘聚焦 2 个关键问题与 1 个亮点，并提供近似启发式说明及专项跳转。
- 趋势面板展示样本局数、决策数、时间窗和算法版本；不足 3 局或每维不足 5 次决策时明确显示“数据积累中”。
- 优化 390px 手机端牌桌、手牌、牌河和固定操作区，主按钮保持触控尺寸，避免横向溢出。

## 验证

- `npm run build`：通过
- 全仓 lint 仍有基线格式问题，本轮触及文件已完成定向检查；未修改历史无关格式。
